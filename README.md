# Tecno Riv · Maqueta del local

App web instalable (PWA) con la maqueta 3D del local de Tecno Riv.
No contiene datos: al abrirla pide iniciar sesión y trae los números en vivo desde la base del negocio.
Solo el usuario dueño puede leerlos.
Esta carpeta la genera `armar-app.ps1`; no la edites a mano.
